## Env Setup

1. Create venv

    ```sh
    python -m venv .venv
    ```
2. Activate venv

    ```sh
    source .venv/bin/activate  # macOS/Linux
    .venv\Scripts\activate.bat # cmd
    .venv\Scripts\Activate.ps1 # powershell
    ```
3. Install requirements

    ```sh
    pip install -r requirements.txt
    ```
