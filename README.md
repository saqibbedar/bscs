# BSCS: Bachelor's in Computer Science

This repository hosts my work I did during my each semester at `Quaid-i-Azam University, Islamabad`. 

# Background Story

Prior making it public, I had maintained all of my work on my local machine. Due to which, many of my work was lost, especially, the contents of `2nd` and `3rd semester`. Overall, the proper maintenance I started during my `5th semester`. And progressively, I am maintaining it.

# Use Case

This repository is a context server for me. It's a recall-manager, whenever, I need to look for a topic I had already covered, I directly prioritize to find the solutions or related work here as it reveals me overall pipeline how did I did approached specific problem and solved it. Hence, I can call it as my context-manager which reveals my footprints.

## Folder Structure

I think, the folder structure is quiet easy, at root level you find `folder/directory ` representing `semester` with dedicated semester name, i.e., `sem_x`. Internal structure is heterogenous but most probably you are going to find this structure defined in a subscript operator or an array `[assignments, quizez, papers | pastpapers, class_material [lectures, slides, books], videos, notes, etc.]`.

# Does it create any usability for you?

Well, I think yes if you are computer science student. You can check out assignments, topics, books, notes, exercises, solutions, etc., and I think it can reveal you a computer science roadmap what actually gonna learn.
